# Les Toitures d'Elma - Site Web

Site vitrine moderne pour l'entreprise de couverture **Les Toitures d'Elma**, basée à Briou (41), Loir-et-Cher.

## Technologies

- React 18
- Vite 6
- Pure CSS

## Développement

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
